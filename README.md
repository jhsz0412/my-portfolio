## Getting Started

Clone the repository:

```bash
git clone https://github.com/saezjhs-0412/pads-portfolio.git
cd pads-potfolio
npm install
npm run dev
```

Then open the local development server in your browser.

---

## Build for Production

```bash
npm run build
```

This project is set up for a Vite production build and TypeScript compilation.
